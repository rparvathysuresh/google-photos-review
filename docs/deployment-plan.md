# Railway Deployment Plan

This document outlines the step-by-step plan to deploy the Google Photos Discovery Engine to [Railway](https://railway.app). 

Since this project consists of a FastAPI backend and a Vite+React frontend, we will deploy them as two separate services within a single Railway project.

## 1. Project Preparation

### Backend Adjustments
1. **Start Command**: We created `run.py` at the root. We will configure Railway to run `python run.py`.
2. **Path Resolution**: The SQLite database and ChromaDB have been configured to route to `/tmp` dynamically when deployed on Railway to prevent Network File System (NFS) deadlocks.

### Frontend Adjustments
1. **API URL Environment Variable**: The frontend currently uses `import.meta.env.VITE_API_URL`.

---

## 2. Railway Environment Setup

1. **Create Project**: Go to the Railway dashboard and create a new project from your GitHub repository.
2. **Monorepo Setup**: Railway will scan the repository. You must add two services from the same repo:
   - Service 1: **Backend** (Root Directory: `/`)
   - Service 2: **Frontend** (Root Directory: `/frontend`)

---

## 3. Backend Service Configuration (FastAPI)

1. **Root Directory**: Set to `/` (the root of the repository).
2. **Build Command**: Railway's Nixpacks will automatically detect Python.
3. **Start Command**: `python run.py` (Must be set in Railway's custom Start Command setting).
4. **Environment Variables**:
   - `GROQ_API_KEY`: Add your API key.
   - `PORT`: `8000` (Railway will automatically assign this).
   - `BACKEND_CORS_ORIGINS`: (Leave blank for now, you will update this later).

---

## 4. Frontend Service Configuration (Vite/React)

1. **Root Directory**: Set to `/frontend`.
2. **Build Command**: `npm install && npm run build`
3. **Start Command**: `npm i -g serve && serve -s dist -l $PORT`
4. **Environment Variables**:
   - `VITE_API_URL`: Set this to the public URL generated by Railway for the Backend service (e.g., `https://backend-production-xyz.up.railway.app/api`).

---

## 5. Deployment Steps & Validation

1. **Deploy Backend First**: 
   - Wait for the backend to build and go live.
   - Generate a public domain for the backend in Railway settings.
   - Check the `https://<backend-url>/api/health` endpoint to ensure it's running.
2. **Deploy Frontend Second**:
   - Inject the newly generated backend domain into the frontend's `VITE_API_URL` environment variable.
   - Wait for the frontend to build and go live.
   - Generate a public domain for the frontend.
3. **Update Backend CORS**:
   - Add the frontend's public domain to the backend's `BACKEND_CORS_ORIGINS` environment variable so the API accepts requests from the live React app.
4. **Run Data Ingestion**:
   - Trigger the `/api/ingest/` endpoint locally or via a script to seed data.
